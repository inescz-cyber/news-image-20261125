A 1024x1024 infographic summing up 25 November 2026 world news in one image: US tariffs on 14 economies, a Houthi strike on Riyadh's financial district and a Ras Tanura refinery claim, China launching Shenzhou-24 (first foreign crew on Tiangong), Huawei convicted in a US trial, a Solomon Islands-Australia security treaty, plus a Cairo tanker fire and a Bangladesh wage rise.

## Run it

```sh
python3 main.py
```

`main.py` validates `entry.png` (1024x1024, at most 1 MiB) and copies it to `/output/entry.png`. `draw_news.py` draws the infographic with PIL.
